## Prefixes for GIT

- *`doc`* - Documentation
- *`editor`* - Editor stuff
- *`importer`* - Custom importers
- *`ja2`* - Global one
- *`main_menu`* - Main menu
- *`prefab`* - Things that hat to do something with prefabs
- *`script`* - Generic things that has something to do with scripting but couldn't be categorized further
